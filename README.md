## 📖 درباره پروژه

این پروژه یک **شبیه‌سازی سه‌بعدی تعاملی** از سامانه‌ای است که با استفاده از **کوادکوپتر مجهز به دوربین فراطیفی** و **مدل‌های یادگیری عمیق**، تناژ چغندرقند را به‌صورت **برخط (Real-time)** در مزرعه پیش‌بینی می‌کند.

هدف اصلی این طرح، جایگزینی روش‌های سنتی و پس از برداشت با یک راهکار هوشمند، سریع و غیرمخرب است تا کارخانه قند بتواند پیش از برداشت، از میزان تناژ و کیفیت محصول مطلع شود.

---

## 🎯 اهداف طرح

- 🛰️ **پایش هوایی مزرعه** با کوادکوپتر مجهز به دوربین فراطیفی
- 🧠 **پیش‌بینی برخط تناژ** با استفاده از مدل‌های یادگیری عمیق (CNN)
- 🌱 **تشخیص غیرمخرب** ریشه‌ها بدون آسیب به محصول
- 📊 **پوشش ۱۰۰٪ مزرعه** در یک دور کامل پرواز دورانی
- ⚡ **پردازش لبه‌ای** (Edge Computing) بدون نیاز به اینترنت
- 🎯 **دقت بالا** با R² ≥ ۰.۸۵ و خطای RMSE < ۸٪
- 🔒 **حفظ محرمانگی داده‌ها** با مخزن خصوصی
